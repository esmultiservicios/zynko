# ZYNKO V2.31.120

## Navegación lateral premium
Esta entrega reorganiza el menú lateral para reducir altura y evitar scroll innecesario sin eliminar accesos funcionales.

### Nueva organización
- NIVO Web Chat → Encuestas y satisfacción.
- NIVO IA → Automatizaciones.
- Canales → Integraciones.
- Configuración → Logs y diagnóstico.

### Interfaz
- Scrollbar premium oscuro/teal, redondeado y discreto.
- Submenús flotantes con tarjetas compactas, iconos uniformes y hover suave.
- En móvil/tablet táctil, los submenús se abren como panel inferior premium para conservar acceso sin llenar el menú principal.
- El módulo padre permanece resaltado cuando se navega a un submódulo.

## Base de datos
No requiere actualización de base de datos.
