# ZYNKO V2.31.127

## Sitio público y showcase

- Galería pública actualizada con las capturas recientes entregadas para ZYNKO.
- Zonas visualmente sensibles de las capturas incluidas se protegen antes de publicarse.
- Cursor de zoom sobre la imagen y acción **Ver más** siempre visible.

## Administración exclusiva del Owner

- Nueva opción **Configuración → Sitio público · imágenes** visible únicamente para el Owner de la empresa principal.
- Cada vista puede reemplazarse mediante arrastrar y soltar, pegar desde portapapeles o seleccionar archivo.
- Permite editar área, título y descripción, y restaurar la captura incluida con ZYNKO.
- Los cambios se guardan como contenido persistente del servidor y no requieren cambios de base de datos.

## Base de datos

No requiere UPDATE DB.
