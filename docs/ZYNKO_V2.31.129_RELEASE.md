# ZYNKO V2.31.129

## Mensajería humana y emojis

- Los mensajes automáticos de asignación ya no incrustan Markdown ni `\n` literal en el cuerpo.
- El autor humano se identifica como **Agente - Nombre - Empresa** y el mensaje inicia con un saludo natural.
- Los mensajes heredados con el formato anterior se limpian al renderizarse en Bandeja y NIVO Web Chat.
- El selector de emojis recupera categorías visuales legibles y claramente separadas del contenido.
- No requiere actualización de base de datos.
